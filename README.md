# pango_adas_system
本作品基于紫光同创RK3568_MES2L100H，构建了一套软硬协同的高级辅助驾驶系统（ADAS）。系统充分发挥 FPGA 的并行流水线优势，通过 OV5640 双目摄像头实时采集道路环境图像，在 FPGA 端完成灰度化、去噪、边缘检测等预处理，并通过 PCIe 高速接口与 ARM 端协同通信。ARM 端部署轻量级 AI 模型，实现对斑马线、行人、路障及车道线的实时识别。系统完整模拟了十字路口红绿灯启停、虚实线变道决策、超速/碰撞预警、转向灯联动等典型驾驶场景，支持按键切换车道及模拟强制违规报警，整体处理延迟满足 ADAS 低时延需求，具备良好的工程实用性与可演示性
