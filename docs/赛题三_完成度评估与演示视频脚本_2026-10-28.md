## 一、赛题原文要点（选题三）

**基础任务**
1. 图像采集与显示：HDMI/摄像头 → LCD/HDMI，完成"采集-处理-显示"全流程闭环，实现道路环境感知。
2. 软硬协同通信：MCU 与 FPGA 之间高速通信（如 PCIe），完成数据交互与指令控制。
3. 图像处理与识别：基于 FPGA 实现道路环境监测与特定场景感知。

**高阶任务**
1. 多路图像采集与低延迟传输：至少 4 路（模拟车前后左右）并行采集与低延迟传输，优化带宽。
2. 复杂应用场景构建：夜间道路、复杂交通路口等，构建完整感知与避障。
3. AI 模型部署与实时识别：MCU 端部署轻量模型，多路实时高精度低延迟识别 + 自主道路规划与辅助驾驶。

**测评标准**
1. 图像采集与处理：（1）一路或多路、能做拼接/融合模拟全景；（2）基础图像处理：**灰度化、去噪、二值化、色彩空间转换**；（3）整体延迟与实时帧率满足低延迟。
2. 场景构建与工程价值：（1）强光/夜间/复杂路口场景的自主规划；（2）AI 实时处理、识别准确率高、端到端延迟低；（3）更真实的道路效果模拟与呈现。
3. 测试方式（现场 U 盘给场景）：(1) 十字路口三车道：红灯停、绿灯行、红灯强制行驶→报警；用**图像叠加左/右/直箭头**或 LED 指示行驶行为；按键模拟切换车道、模拟停止/行驶；用叠加红色或 LED 模拟报警。(2) 虚实线：虚线变道、实线直行、强制实线变道→报警；按键模拟左右转向。(3) 带导航的真实道路视频，按导航完成模拟智驾。(4) 其他 1–2 个场景，如行人闯红灯刹车。
4. 技术实现与文档：代码规范（模块化/时序约束/注释、无明显违例）；提交《系统架构设计 + 软硬协同数据流分析 + 资源占用 + 性能测试》报告。

**提交材料（第 14 页原文）**：完整技术文档（含核心亮点预览）、硬件实物、**1080P 演示视频（3 分钟以内）**、打包工程源码。

### 0. 总原则
- **3 分钟硬上限**，建议成片 **2′40″–2′55″**，留余量。
- 视频要满足三件事：①能看到**硬件实物**（板卡、子卡、接线、显示器）；②能看到**屏上实时效果**（清晰、无摩尔纹）；③按赛题 4 类测试方式**逐条演一遍**，每条都有对应按键动作与画面变化。
- 录制方式：**主画面用板端录屏**（`ffmpeg -f kmsgrab` 直接抓 DRM 帧，60fps、无摩尔纹），**穿插手机实拍**（展示实物/按键/接线）。最后统一缩放到 1920×1080 输出。

### 2. 录制与剪辑命令（可直接用）

**A. 板端录屏（推荐主画面，60fps 无摩尔纹）**
```sh
# 串口执行；时长 60 秒、1280x720 -> 1000 宽（后期再放大到 1080P）
ffmpeg -y -loglevel error -f kmsgrab -framerate 60 -i - -t 60 \
  -vf "hwdownload,format=bgr0,scale=1920:1080:flags=lanczos" \
  -c:v libx264 -preset veryfast -crf 20 -pix_fmt yuv420p /tmp/clip1.mp4
```
> 注意：app 重启后 DRM plane 会重建，`kmsgrab` 可能报 `No usable planes found.` → **每条片段开录前先确认 app 已稳定运行 20 秒以上**；失败就重启 app 再录。

**B. 手机实拍**：1080P/60fps，横屏，三脚架或靠稳；拍板卡全景 + 特写接口 + 手指按键；注意避开显示器反光（侧 15° 拍）。

**C. 后期（Windows，ffmpeg 已在 PATH 请自行确认）**
```powershell
# 单片段统一转 1080p60
ffmpeg -i clip1.mp4 -vf "scale=1920:1080:flags=lanczos,fps=60" -c:v libx264 -crf 20 -pix_fmt yuv420p clip1_1080.mp4
# 拼 3 段并加淡入淡出
ffmpeg -i a.mp4 -i b.mp4 -i c.mp4 -filter_complex "[0:v][1:v][2:v]concat=n=3:v=1:a=0[v]" -map "[v]" -c:v libx264 -crf 20 out.mp4
# 烧字幕（把字幕写成 subtitles.srt / 或用 drawtext 逐条）
ffmpeg -i out.mp4 -vf "subtitles=subs.srt:force_style='FontName=Microsoft YaHei,FontSize=28,PrimaryColour=&H00FFFFFF,BorderStyle=3'" -c:v libx264 -crf 20 final.mp4
```
（没有 ffmpeg 就用剪映/必剪：导入片段 → 缩放到 1080P → 加中文字幕 → 导出 1080P ≤3 分钟。）
