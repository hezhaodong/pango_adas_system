# YOLOPv2 车道中心点细线试验版

本版本只验证“粗 laneMask -> 每个水平条带中心点 -> 细红线”的显示效果。

改动：
- laneMask 仍保留并继续供车道分析使用，但不再直接作为粗红色区域叠加显示。
- LaneDepartureAnalyzer 每个扫描条带得到的 bestLeft / bestRight 中心位置会保存到结果结构中。
- OverlayRenderer 用 3 px 红线连接这些中心点，并在每个样本位置绘制白心红圈，便于观察远端重叠后的中心漂移。
- 黄色近场拟合线与黄色虚线延长保持原逻辑。
- 暂时关闭上一版“同起点合成细红二次曲线”的显示，避免与真实中心点轨迹混淆。
- 道路方向判断内部逻辑暂不改，本版的目的只是看中心点提取是否可靠。

观察重点：
1. 近处左右中心点是否落在粗车道区域的几何中心。
2. 虚线车道缺口处，连接线是否仍保持合理趋势。
3. 远端两条 laneMask 粘连时，白心红点是否突然跳到两条车道之间。
