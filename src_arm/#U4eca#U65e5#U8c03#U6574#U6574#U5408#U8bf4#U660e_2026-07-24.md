# ARM_final1 今日调整整合说明

日期：2026-07-24

## 整合原则

本次以 `ARM_final1` 为母工程，保留其 IP Camera 输入、WiFi 控制和原有多输入逻辑，只同步 `ARM_final` 中今天确认的最终 AI、显示和状态管理调整。

## 已整合内容

### 车牌识别

- 第一个有效 LPR 结果立即显示。
- 最近 10 次结果中同一完整字符串达到 7 次后更新稳定字符。
- 字符投票仅用于抑制跳字，不再控制 ID 分配。
- 首次有效车牌立即获得公共 ID。
- 字符相差 0～2 位保持原 ID；相差 3 位及以上立即切换到不同 ID。
- 几何轨迹 ID 只在 Worker 内部使用，对外显示字符公共 ID。
- LPR 完成后执行跨类别车牌框去重，优先保留当前帧成功识别出字符的框。
- 无公共 ID 的临时结果显示为“待确认”，不写入共享 `-1` 历史。

### 礼让行人检测

- 行人侧支持 `person`、`pedestrian`、`people`、`rider`、`motor`。
- 车辆侧支持 `car`、`vehicle`、`bus`、`van`、`truck`。
- 行人侧框横向扩展为原宽度 3 倍。
- 检测到斑马线后开启 1 秒人车重合判定窗口。
- 新斑马线检测会重新开始 1 秒计时。
- 斑马线框不保持，只显示当前帧实际检测结果。
- 报警文字画在车辆框上，并同步进入 WiFi JSON 结果。

### 显示与日志

- AI Worker 不再生成整帧 ARGB 标注图，由界面统一绘制矢量框。
- 车牌完整结果只在 LPR 和公共 ID 处理完成后发布。
- 删除 AI 帧率和 AI 耗时显示。
- 发布构建通过 `QT_NO_DEBUG_OUTPUT` 关闭普通调试输出。
- 默认关闭 LPRNet 逐字符日志，保留模型及 RKNN 错误输出。
- YOLO 标签读取支持清除 BOM、行首尾空白及 Windows 换行符。

### 输入切换

- 保留 `ARM_final1` 原有 PCIe/FMC、PCIe/HDMI、WiFi 和 IP Camera 输入。
- FMC/HDMI 物理输入切换时重置车牌 Worker 和交通 Worker 的场景状态。
- 输入切换后清除旧帧、车牌历史、公共 ID 和斑马线判定窗口，防止跨场景污染。
