# 车道方向：红线中心曲线 vs 黄色延长线

本版本不再使用“分段转角”作为最终道路方向判断。

## 显示含义

- 红色半透明粗带：YOLOPv2 `laneMask` 原始车道分割。
- 黄色实线：程序原有的左右车道 RANSAC 直线拟合，保持原逻辑不变。
- 黄色虚线：从黄色实线顶端继续向前延长。
- 细红线：把远处红色粗车道的中心点压成一条受约束的二次曲线。

细红线被强制满足两件事：

1. 与黄色实线顶端使用同一个起点；
2. 在起点处与黄色线使用同一个初始方向。

因此细红线相对黄色虚线只表示“后续弯曲”，不会把起点位置差或初始斜率差误当成弯道。

## 数学形式

设黄色线顶端为锚点 `(x0, y0)`，黄色直线斜率为 `k`，远端比较高度为 `yFar`：

```text
u = (y0 - y) / (y0 - yFar)

yellowX(y) = x0 + k * (y - y0)
redX(y)    = yellowX(y) + D * u^2
```

`D` 就是最远比较位置的“红黄横向差”：

- `D < 0`：红线中心在黄色延长线左边，判左弯；
- `D > 0`：红线中心在黄色延长线右边，判右弯；
- `D` 接近 0：判直行。

当前阈值为：

```text
max(10 px, 黄色顶端车道宽度 * 4%)
```

左右两侧都有效时进行加权融合；如果左右两侧出现明显相反方向，则本帧视为无效（不处理 S 弯）。方向仍需连续 3 帧确认。

## 屏幕调试信息

右上角第二行改为：

```text
红黄差 左-xx.xpx 右-xx.xpx
```

负数表示向左偏离黄色延长线，正数表示向右偏离黄色延长线。
